# 日本茶インストラクター試験クイズ

日本茶インストラクター認定試験 **第一次試験**（2026年11月8日）対策の五肢択一クイズアプリです。
スマートフォンのブラウザで開いて使います。ホーム画面に追加すればオフラインでも動きます。

## 使い方

### スマートフォンで使う

1. 上の公開URLをブラウザで開く
2. ブラウザのメニューから「ホーム画面に追加」を選ぶ
3. 以降はアイコンから開ける。電波がない場所でも解ける

### 4つのモード

| モード | 内容 |
|---|---|
| **分野を選んで解く** | 10分野から1つ選び、その分野から10問 |
| **間違えた問題だけ復習する** | 直前に間違えた問題だけを自動で集めて出題 |
| **本番形式の模試** | 全分野から50問・制限時間75分。途中で正誤も解説も出ない |
| **正答率** | 分野ごとの正答率を棒グラフで表示 |

選択肢は**表示するたびに並び替わります**。「答えは3番目」と位置で覚えてしまうのを防ぐためです。

## 「※ テキストで要確認」の印について

**このアプリで最も大事な仕組みです。**

協会の養成講座テキストは転載複製禁止のため、問題は公開されている資料をもとに作っています。そのため、公開資料だけでは確かめきれない論点がどうしても残ります。

そうした問題には **「※ テキストで要確認」** の印が付きます。

- 印が**ない**問題 … 公開資料で裏付けを取り、出典URLと確認日を付けてある
- 印が**ある**問題 … 裏付けが取れていない。**手元のテキストで必ず確かめてください**

印のある問題を隠さずに出しているのは、隠すと試験範囲に穴ができてしまうからです。

### 統計の数字について

統計を問う問題には「令和7年における」などの**年次を必ず明記**しています。
手元のテキストと数字が違っても、多くの場合は**年次が違うだけ**です。

## 開発者向け

外部ライブラリを使っていないので、`npm install` は不要です。

```bash
npm start
```

で `http://localhost:8080` が立ち上がります。

### 問題を追加する

`data/questions.json` に追記します。1問の形は次のとおりです。

```json
{
  "id": "chemistry-041",
  "category": "chemistry",
  "question": "問題文",
  "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4", "選択肢5"],
  "correctIndex": 0,
  "explanation": "解説",
  "source": {
    "name": "資料名",
    "url": "https://...",
    "confirmedDate": "2026-09-13"
  },
  "verified": true
}
```

裏付けが取れていない問題は `"verified": false` とし、`source` は書きません。

### 追加したら必ず検査する

```bash
npm test
```

次のことを自動で見張っています。

1. 選択肢がちょうど5つあるか（本番が五肢択一のため）
2. 正解の番号が選択肢の範囲内の整数か
3. 同じ選択肢が2つ以上ないか
4. IDが重複していないか
5. 分野IDが10種のいずれかか（打ち間違いを検出）
6. `verified: true` なら出典URL（http/https）と確認日（YYYY-MM-DD）があるか
7. 問題文と解説が空でないか
8. 正解の位置が特定の場所に偏っていないか

### 正解の位置を散らす

作問していると「正解をつい1番目に書く」癖が出ます。次のコマンドで機械的に均等へ散らせます。

```bash
node tools/shuffle-choices.mjs
```

`--dry-run` を付けると、書き込まずに分布だけ表示します。

### 分野ごとの作問スクリプト

`tools/gen-*.mjs` に、分野ごとの問題と出典が入っています。問題を直すときはこちらを編集してから実行すると、出典の対応が崩れません。
